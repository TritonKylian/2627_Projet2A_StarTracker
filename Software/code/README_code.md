# Code pour le Projet
## Installation
### Librairies nécessaires :
Requirements.txt contient toutes les librairies nécessaires pour le projet. Pour les installer, utilisez la commande suivante dans votre terminal :

```bash
pip install -r requirements.txt
```

### Lancement du serveur Django :
Pour lancer le serveur Django, utilisez la commande suivante dans votre terminal :

```bash
python JSP # je viens de commencer à essayer de comprendre
```
